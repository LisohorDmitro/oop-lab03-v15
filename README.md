# Лабораторна робота №3 — варіант 15

Конструктори та деструктори в C++

Варіант 15 із лабораторної №2: створити клас Fraction для роботи із дробовими числами. Число подати двома закритими полями: ціла частина — довге ціле зі знаком, дробова — беззнакове коротке ціле. Реалізувати додавання, віднімання, множення та порівняння, а також Init(), Read(), Display(), toString(). На основі проєкту лабораторної №2 реалізувати щонайменше три конструктори та сформувати звіт.

## Збирання і запуск у Windows

Потрібен GCC MinGW-w64 з підтримкою C++14. Додайте каталог `bin` компілятора до `PATH` або передайте його скрипту через параметр `-CompilerDirectory`.

```powershell
.\build.ps1
Get-Content .\input.txt | .\lab03.exe
```

Команди збирання

```text
g++ -std=c++14 -O2 -Wall -Wextra -pedantic -static-libgcc -static-libstdc++ fraction.cpp main.cpp -o lab03.exe
```

У `input.txt` збережені тестові вхідні дані, а в `expected_output.txt` — вивід перевіреного запуску.
